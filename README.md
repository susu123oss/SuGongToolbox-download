# 苏工工具箱下载与功能说明

**SOLIDWORKS 机械设计工程自动化工具箱**

本仓库用于发布苏工工具箱正式安装包。插件直接运行在 SOLIDWORKS 内部，面向装配体配孔、压铆紧固件、平面刻字、轻量线束、装配体焊缝、标准孔、颜色、CAD 视图、工程图整理与导出、项目打包和带工程图改名等高频机械设计工作。

> 支持 **SOLIDWORKS 2018–2026（64 位）**。

## 下载与安装

请从本仓库 **Releases / Latest** 下载最新版本：

**https://github.com/susu123oss/SuGongToolbox-download/releases/latest**

安装步骤：

1. 保存工作并关闭 SOLIDWORKS。
2. 下载 `SuGongToolbox-setup-vX.X.X.exe`。
3. 右键以管理员身份运行安装程序（正常双击也会请求 UAC）。
4. 安装完成后重新启动 SOLIDWORKS。
5. 顶部会出现 **“苏工工具箱”** CommandManager 页签。

插件内也可以通过 **苏工工具箱 → 版权声明 → 检测更新** 获取新版本。下载完成后会校验 SHA-256，再等待 SOLIDWORKS 正常退出后执行安装。

## 1. 批量配孔

**适用：装配体。** 用于机柜、钣金箱、安装板、支架之间的配孔：一侧已经有孔，希望另一侧准确跟着打，而不是人工量坐标。

### 选择和识别

- 参考平面支持多选。
- 目标打孔平面支持多选。
- 可以直接指定若干参考孔，只处理需要的孔。
- 自动识别可选：圆孔、半圆、长腰形中心。

### 孔参数

- 普通圆孔。
- 螺纹孔。
- 间隙孔。
- 沉孔 / 沉头孔等标准 Hole Wizard 输出。
- 支持直径/公称规格、孔深、有效螺纹深度、贯穿等参数。

### 保持参考

开启“保持参考”后，目标孔位会尽量使用 SOLIDWORKS 原生外部参考关联到源孔，后续源孔移动时目标孔能够跟随，而不是只复制一次坐标。

### 批量与整理

- 支持多个目标面和装配体在位编辑。
- 按规格自动整理特征，如 `批量配孔-φ4`、`批量配孔-M5-螺纹`。
- 执行时有进度、健康检查和失败回滚。

**适合：** 机柜侧板与横梁、门板与铰链、安装板与支架、箱体上下层钣金之间的快速配孔。

## 2. 钣金压铆

**适用：零件 / 装配体。** 用于压铆螺母、压铆螺柱、压铆螺钉等 PEM 类紧固件的快速批量布置。

### 自动识别

- 安装面可多选。
- 自动扫描面内圆孔，也可以限定孔区域。
- 根据实际孔径和孔径容差匹配规格。
- 同一批次允许多种孔径、多种规格。
- 支持反向安装。

### 规格管理

- 内置压铆螺母、螺柱、螺钉模板。
- 支持用户自定义规格。
- 自定义规格可保存、导入、导出，便于公司内部或客户之间共享。
- 对允许调整高度的规格可直接修改有效高度。

### 零件与装配体

- 零件模式直接在当前零件中生成压铆实体、安装孔和必要参考。
- 装配体模式可在装配上下文定位宿主零件并完成孔与压铆件创建，尽量不弹出一堆后台零件窗口。
- 大批量时按规格复用几何/阵列策略，降低重复建模时间。

### 特征树

- 按规格建立 `钣金压铆-规格` 文件夹。
- 安装孔、定位参考、压铆实体尽量按同一规格归档。
- 关键步骤失败支持回滚；仅文件夹整理异常不会撤销已经有效的几何成果。

---

## 3. 平面刻字

**适用：零件 / 装配体。** 支持原生钣金、普通实体以及 STEP 等导入实体的平面。

### 自动排版

- 选择刻字面后读取可用边界。
- 可选择常用文字预设，也可输入自定义文字。
- 设置边缘安全距离。
- 自动避开边缘、孔洞和明显障碍区域。
- 自动计算可放下的较大文字尺寸。
- 横向放不下时会尝试 90° 旋转布局。

### 真实特征

生成的是 SOLIDWORKS 草图文字与刻字/包覆特征，不是截图或临时注释；后续仍能在特征树中找到和修改。

### 导入实体

没有钣金特征历史也可以使用，只要目标是可识别的平面。适合客户 STEP 件、采购件和无历史模型快速加工艺文字。

## 4. 轻量线束

**适用：装配体。** 面向储能柜、机柜、电气箱等快速布线场景，不要求建立完整 SOLIDWORKS Routing 数据库。

### 起点 / 终点

- 起点选择连接面。
- 再选边线、轴或方向参考定义出线方向。
- 终点同样支持连接面 + 出线方向。
- 起点/终点可以单独反向。
- 端部直线长度可调整，避免线刚出端子就急弯。

### 中间必经几何

- 可按顺序选择多条边或多个面作为必经引导。
- 适合让线束经过霍尔、线夹、穿线孔、线槽入口或指定壁面附近。

### 实时预览与避障

- 支持黄色半透明实时路径预览。
- 预览考虑实际线径，而不只是无厚度中心线。
- 简单区域直连，复杂区域进行局部绕障和路径搜索。
- 会结合线径/最小弯曲半径检查路径。
- 在可行时自动增加过渡控制点，让路径更平滑。
- 首尾方向受结构干涉时可以评估反向出线，优先更短、更顺的路径。

### 生成与人工调整

- 每根线束生成独立外部零件。
- 使用 3D 草图 / Style Spline 保存路径。
- 创建路径后进入草图编辑，中间控制点可以拖动微调。
- 首尾连接和端部直线保持约束，避免端子出线被拖歪。
- 确认退出路径编辑后生成圆截面扫描实体。
- 路径草图继续保留，后续仍可重新编辑。
- 记录线束长度/拉直长度等信息。

### 其他

- 提供 AWG / EV 等线缆规格入口。
- 可设置线缆相色。
- 支持连续布线作业。
- 自动生成的线束零件采用静默后台方式处理，并尽量不污染 SOLIDWORKS“最近打开”。

## 5. 添加焊缝

**适用：装配体。** 用于快速建立角焊缝几何。

### 选择

- “要焊接的面”支持多选。
- “要添加的焊缝”支持多条边/路径多选。
- 可一次生成多条焊缝。

### 连续焊

- 设置焊脚尺寸后沿有效路径生成三角角焊缝。
- 自动根据两焊接面的理论交线校准焊根位置。
- 处理镜像件、翻转装配和法向相反等常见装配姿态。

### 断续焊 / 定位焊

- 焊段长度 L。
- 中心间距 P。
- 两端避让 Margin。
- 自动计算均匀、对称的分段位置。
- 规则重复段优先使用实体阵列，减少大量重复扫描。

### 智能避让

- 可自动避让孔洞、缺口和局部悬空区域。
- 路径或截面方向异常时提供多级几何重试。

### 预览与工艺信息

- 支持实时黄色预览。
- 生成后保持明显高亮，复杂装配里容易找到。
- 写入焊缝形式、焊段长度、中心间距等自定义属性。
- 记忆上一次参数，适合连续焊接作业。

## 6. 批量打孔

**适用：零件。** 它和“批量配孔”不同：批量打孔直接在当前零件建标准孔，不要求另一侧先存在参照孔。

### 支持孔型

- 螺纹孔。
- 间隙孔。
- 柱形沉孔。
- 90° 沉头孔。
- 普通圆孔。

### 参数

- 公称规格或普通孔直径。
- 孔深度。
- 有效螺纹深度。
- 贯穿 / 盲孔等终止方式。

标准孔尽量使用原生 Hole Wizard，普通孔按直径创建。创建失败、定位草图异常或重建失败时会回滚本轮特征。

## 7. 设置颜色

**适用：零件 / 装配体。** 用于方案区分、企业外观标准、钣金喷涂预览和透明检查。

- 内置标准色库，包含项目内置 RAL / PANTONE 等颜色数据。
- 支持关键词搜索。
- 支持 RGB 直接调整。
- 支持透明度。
- 支持网格/列表浏览。
- 界面会显示当前目标，降低刷错对象的概率。
- 颜色窗口支持高 DPI 和多屏显示。

## 8. 视图转CAD

**适用：已保存的零件 / 装配体。** 用于不建立正式工程图也要快速给出二维 DWG 的场景。

### 支持

- 当前模型视角。
- 标准正投影视图。
- 多视图排布。
- 轴测视图。
- 第一角法 / 第三角法布局。
- 视图间距控制。

### 预览与导出

- 后台创建无图框临时工程图做真实预览。
- 用真实可见边几何校正视图边界和间距。
- 多次调整时复用临时工程图/缓存，减少反复生成。
- 输出按 1:1 基准处理。
- 已认证的预览在模型和参数未变化时可直接复用到最终 DWG。
- 临时工程图不会作为客户工程文件长期保留。

- 装配体中有明确目标组件时，可快速定位组件文件目录。

## 10. 工程图导出

**适用：SOLIDWORKS 工程图。**

### 格式与输出

- PDF。
- DWG。
- 可以同时导出。
- 可设置输出目录。
- 可自动覆盖。
- 可在结束后自动打开输出目录。

### 保留原工程图

导出直接使用当前工程图，不新建客户可见临时 `.SLDDRW`，也不改原文件路径、Sheet、视图比例、图框、标题栏或标注。

### DWG 图层标准化

可在导出前整理/映射常用对象：

- 粗实线 / 细实线。
- 中心线。
- 隐藏线 / 虚线。
- 剖面线。
- 尺寸。
- 焊接符号。
- 形位公差。
- 表面粗糙度。
- 注释。

导出过程有进度和详细日志。

## 11. 整理尺寸

**适用：工程图。** 自动重新布局已有 SOLIDWORKS 原生尺寸。

- 识别常见线性、径向尺寸。
- 按视图和图纸边界建立布局区域。
- 按层级安排内外尺寸。
- 使用常用 10/7 mm 间距策略做初始排布。
- 检查尺寸文本、尺寸线和相邻标注碰撞。
- 拥挤时评估换侧。
- 小尺寸尽量靠内、大尺寸靠外。
- 径向尺寸使用独立候选位置和避碰评分。
- 合适的同通道尺寸调用 SOLIDWORKS 原生 Align Dimensions 做最终共线。

不会把尺寸转换成静态线/文字，整理后仍然是原生尺寸。

## 12. 自动中心线

**适用：工程图。** 建议先选中一个模型视图，一次处理一个视图。

### 支持识别

- 完整圆孔中心标记。
- 半圆 / 多段圆弧组合圆。
- 整件水平/垂直中心线。
- 圆柱、轴类投影中心线。

### 原生模型与导入件

原生 SOLIDWORKS 模型优先调用原生能力；STEP / X_T / IGES 等没有特征历史时再用几何圆、圆弧和轴向关系补识别。

### 减少误标

- 过滤隐藏边。
- 过滤背面圆。
- 过滤前方遮挡的不可见孔。
- 过滤同心重复标记。
- 检查已有中心线/中心标记，尽量不重复创建。

## 14. 带工程图改名

**适用：零件 / 装配体。** 用于“改模型名但不想把工程图和装配引用改坏”。

### 直接改名

- 改模型文件。
- 有同名工程图时同步改工程图。
- 更新装配体/上层模型中的引用。
- 改名前检查重名和路径冲突。

### 生成独立副本

- 对所选组件做 Make Independent 类独立派生。
- 可生成子级组件独立计划并应用后缀。
- 对应工程图同步复制/处理。
- 适合从标准机型快速派生客户项目。

### 失败保护

模型、图纸、引用按事务执行；中途失败会尽量回滚到旧名字和旧引用，并写入诊断日志。

## 已移除的旧功能

旧版右侧 **“参数化设计工具”** TaskPane、Excel 参数模板、任务清单、参数采集与批量参数驱动引擎已经移除。

当前产品聚焦上面的 15 项独立工程工具，不再提供旧版“参数化模板与 Excel”入口。这样可以减少 SOLIDWORKS 启动时无用任务窗格、旧事件链和模板代码负担。

## 日志与问题反馈

主日志通常位于：

```text
C:\Program Files\BZXParametric\load.log
```

如果 Program Files 不可写，会回退到：

```text
%LOCALAPPDATA%\BZXParametric\load.log
```

遇到配孔、压铆、线束、焊缝、工程图等问题时，建议同时提供：

1. SOLIDWORKS 年份与 SP 版本。
2. 操作前选择了什么几何。
3. 报错截图。
4. 对应时间段的 `load.log`。

这样最容易定位到具体 API 阶段。

## 使用边界

- 自动建模依赖模型本身存在可识别、可重建的 SOLIDWORKS 几何关系。
- STEP / X_T / IGES 等导入实体会使用几何补识别，关键项目仍建议人工复核。
- 轻量线束是快速几何走线工具，不等价于 SOLIDWORKS Routing 的完整电气数据库/BOM 系统。
- 焊缝工具用于几何表达与工艺辅助，具体焊接规范仍以企业标准为准。
- 孔规格、压铆规格、工程图图层与工艺参数请按企业实际标准使用。
